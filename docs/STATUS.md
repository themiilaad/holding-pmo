# وضعیت نسخه MVP اولیه

## چه چیزهایی پیاده‌سازی شده‌اند؟
- داشبورد، فهرست ۲۹ کلان‌پروژه و امکان ایجاد/ویرایش پروژه و تغییر وضعیت آن
- ساختار شکست کار درختی، ویرایش بسته‌ها و دیکشنری WBS
- گانت پویا با محاسبه وابستگی Finish-to-Start و تشخیص چرخه
- نمایش متنی-شبکه‌ای روابط پیش‌نیازی فعالیت‌ها (نمودار گرافیکی تعاملی هنوز ایجاد نشده است)
- تکالیف با مسئول اصلی، همکاران، سررسید، اولویت و وضعیت
- سرفصل‌های هزینه آزمایشی و نگاشت به بسته‌های WBS
- خروجی/بازیابی JSON و نگهداری محلی در مرورگر
- رابط واکنش‌گرا با فونت وزیرمتن و راست‌به‌چپ
- داده آزمایشی ایستگاه انرژی اروند و نام ۲۹ کلان‌پروژه

## چه چیزهایی هنوز عملیاتی نیستند؟
- احراز هویت و رمز عبور سازمانی، ورود SSO و تعریف حساب کاربری
- اعمال مجوز در سطح سرور (Role-Based Access Control)
- پایگاه داده و API امن، همگام‌سازی چندکاربره و بکاپ سرور
- ثبت رویداد غیرقابل‌دستکاری و گردش تأیید رسمی
- مسیر بحرانی CPM، محاسبه float، baseline و ارزش کسب‌شده EVM
- تبادل MSP XML، اتصال به تسکامون، اتصال به Google Sheets
- برنامه‌ریزی منابع، تقویم‌های کاری پیشرفته و روابط SS/FF/SF
- شبکه گرافیکی drag-and-drop و تست‌های خودکار مرورگر

## هشدار امنیتی
این نسخه از localStorage استفاده می‌کند و هیچ احراز هویتی ندارد. **برای داده‌های محرمانه یا استفاده واقعی سازمانی مناسب نیست.** اطلاعات در مخزن عمومی نباید محرمانه یا حاوی اسرار سازمان باشد.

## داده مرجع در برابر داده ساختگی
نام ۲۹ پروژه از فهرست پیشین استخراج شده است. WBS، تاریخ فعالیت‌ها، پیشرفت‌ها، مبالغ و اکثر تکالیف نمونه‌اند؛ وضعیت اجرای پروژه‌ها از داده مرجع نتیجه‌گیری نشده است.
