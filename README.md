# Holding PMO — سامانه مدیریت و کنترل پروژه‌های هلدینگ

این مخزن برای توسعه نمونه اولیه سامانه مدیریت و کنترل پروژه‌های هلدینگ در نظر گرفته شده است.

> هشدار: نسخه اولیه فقط داده آزمایشی دارد. این مخزن در زمان راه‌اندازی **عمومی** بوده است. هیچ قرارداد محرمانه، اطلاعات مالی واقعی یا کلید دسترسی در آن ثبت نشود.

کد نسخه اولیه در شاخه توسعه و Pull Request مربوط ارائه خواهد شد. این سامانه پیش از استفاده سازمانی نیازمند احراز هویت سمت سرور، مجوزهای دسترسی، پایگاه داده پایدار، ثبت رویداد، آزمون امنیتی و استقرار در شبکه داخلی است.
