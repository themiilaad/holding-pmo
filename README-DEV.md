# راهنمای توسعه سامانه کنترل پروژه هلدینگ

**نسخه:** نمونه تعاملی MVP روی شاخه `feat/pmo-mvp`.

## راه‌اندازی لوکال
```bash
npm install
npm run dev
```

## تست فنی
```bash
npm run typecheck
npm run build
```

## فناوری
React 18، TypeScript، Vite و Vazirmatn. داده‌ها اکنون در localStorage مرورگر ذخیره می‌شوند.

## قابلیت‌ها
داشبورد، فهرست پروژه‌ها، WBS، گانت FS، شبکه وابستگی‌ها، تکالیف مشترک، CBS، نقش‌های پیشنهادی و خروجی JSON.

## نمونه استفاده
به «داشبورد مدیریتی» بروید، پروژه «احداث ایستگاه انرژی اروند» را انتخاب کنید و صفحات WBS، گانت و هزینه را بررسی کنید.

## نکته ورود
این نمونه **هیچ صفحه ورود و هیچ نام کاربری یا رمز ثابت ندارد**. اگر Bolt.new یا GitHub یا یک URL میزبان ورود می‌خواهد، ورود مربوط به همان پلتفرم است و با سامانه PMO متفاوت است. نام کاربری و رمز فرضی برای دورزدن امنیت تعریف نشده‌اند.

## قبل از نسخه سازمانی
باید بک‌اند و پایگاه داده سازمانی، مجوزهای سطح رکورد، هویت سازمانی، نسخه پشتیبان امن، ثبت رویداد، تست‌های امنیتی و سازوکار استقرار داخلی پیاده‌سازی شوند. این موارد با پنهان‌کردن دکمه‌ها در رابط کاربری تأمین نمی‌شوند.

برای ریز وضعیت قابلیت‌ها به [STATUS.md](docs/STATUS.md) مراجعه کنید.
